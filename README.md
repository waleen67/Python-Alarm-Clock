# ⏰ PyWake - Python Alarm Clock

PyWake is a simple alarm clock built with Python and Pygame.  
It allows users to set an alarm using the HH:MM:SS format and plays a sound when the alarm time is reached.

## 🚀 Features

- Set alarm using HH:MM:SS format
- Plays sound when alarm triggers
- Simple and beginner-friendly Python project
- Uses pygame for audio playback

## 📦 Installation

Clone the repository:

git clone https://github.com/yourusername/pywake-alarm-clock.git

Go to the project folder:

cd pywake-alarm-clock

Install dependencies:

pip install -r requirements.txt

## ▶️ Usage

Run the program:

python alarm.py

Enter the alarm time in this format:

HH:MM:SS

Example:

07:30:00
